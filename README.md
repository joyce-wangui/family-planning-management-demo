# Family Planning Management System

**Demonstration application for Njoro Sub-County Hospital**

This Streamlit application demonstrates data-driven family planning
service monitoring, commodity stock management, and demand forecasting.

## Features

- Service monitoring dashboard
- Client record management
- Family planning commodity and stock monitoring
- Commodity demand forecasting
- Role-based demonstration login

## Demonstration data and privacy

This deployment is intended for demonstration and educational purposes.
It uses synthetic service and commodity records.

Do not enter real patient information or confidential hospital records.
The demonstration login configuration is not intended for production use.

## Run locally

Install the dependencies:

    python -m pip install -r requirements.txt

Start the application:

    streamlit run streamlit_app.py
